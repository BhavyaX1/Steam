# 🎮 Steam Project

A console-based Steam-inspired game store developed using **Python and MySQL** as a Class 12 project.

## 📌 About

This project simulates a basic game store where users can browse games and DLCs, search for games, make purchases, and view their transaction history. It also includes a separate admin interface for managing games, DLCs, and their prices.

## ✨ Features

### 👤 User
- User registration and login
- Browse all available games
- Browse DLCs
- Browse games by category
- Search for games
- Search for DLCs
- Add a game and DLC to the cart
- Checkout and generate a bill ID
- View transaction history
- Search previous transactions

### 🛠️ Admin
- View all games
- View all DLCs
- Add new games
- Add new DLCs
- Delete games
- Delete DLCs
- Update game prices
- Update DLC prices

## 🧰 Technologies

- **Python**
- **MySQL**
- **MySQL Connector**
- **PrettyTable**

## 📚 Project

This project was created as a **Class 12 Computer Science project** to practice Python programming, functions, SQL queries, database connectivity, and CRUD operations.

The application uses a MySQL database to store user accounts, game and DLC information, and transaction records.
